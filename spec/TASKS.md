# Check-up Intelligence — кто что делает (сдача до 17:30 в Medventures/Haqaton-033)

Всё, что нужно для реализации, лежит в `spec/`:
- `rules.json` — ВСЕ правила (3 пакета PRIME, 6 госскринингов по приказу ДСМ-174/2020, 3 правила по жалобам, порядок маршрута);
- `CONTRACT.md` — вход (анкета) и выход `predict()`;
- `examples.json` — 10 контрольных пациентов с ожидаемым ответом.
Источники: `clinical/` (сайт PRIME, полный текст приказа).

## Даниил — движок (`ml/`)
1. `ml/engine.py`: `predict(input) -> output` по `CONTRACT.md`, правила читаются из `spec/rules.json` (в коде правил нет).
   - `age_year = checkup_year - birth_year` (по году достижения!);
   - пакет — по `age_min/age_max` + женская/мужская часть;
   - скрининг: пол + `age_year` в списке + не в `registered` + не проходил в пределах `repeat_years` (`last_screening`);
   - `prime_overlap` → у обследования две опции (бесплатно в поликлинике / в PRIME сегодня);
   - `red_flag` (боль в груди) → пакет не предлагать;
   - маршрут — из `day_route_order`, только для обследований, которые есть в ответе.
2. `ml/test_examples.py`: прогон `spec/examples.json`, все 10 зелёные — ДО подключения к экрану.
3. Если останется время: прогноз нагрузки госскрининга по месяцам (синтетика прикреплённого населения) — один график «волна / равномерно».
